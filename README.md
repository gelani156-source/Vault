# VAULT 1.0 — MVP

Одностраничное PWA без сервера для GitHub Pages. Загрузите файлы из этого архива **в корень** репозитория, включите Settings → Pages → Deploy from a branch → main / root.

## Возможности
- Главная, имущество, документы, события и настройки
- Создание, изменение, удаление вещей
- Локальное хранение в IndexedDB
- Вложения PDF/JPEG/PNG/WebP (до 12 МБ на файл)
- История обслуживания, даты следующего обслуживания, гарантийные сроки
- Категории, поиск, фильтры
- Полная резервная копия JSON, включая вложения, и восстановление
- Тёмная и светлая темы
- Установка PWA и офлайн-открытие после первой загрузки

## Ограничения
Это **первый функциональный MVP**, а не финальная версия полного ТЗ.
- Нет шифрования, пароля и облачной синхронизации. **Не храните пароли и чувствительные личные документы.**
- Нет фона для напоминаний, календарного экспорта, QR и OCR.
- Валюты **не конвертируются**; переключатель меняет только обозначение. Учитывайте имущество в одной валюте.
- Восстановление JSON проверяет формат и ID, но не обеспечивает полный транзакционный откат между хранилищами при ошибке.
- Браузер может очистить локальные данные. Регулярно сохраняйте JSON-бэкапы.
- PWA на iOS хранит данные отдельно в разных браузерных контекстах. Не рассчитывайте на синхронизацию между Safari и приложением на домашнем экране.
- Для крупных вложений могут быть ограничения IndexedDB.

## Проверка
Проверьте в Safari: добавить вещь, отредактировать, прикрепить файл, открыть его, добавить обслуживание, скачать бэкап, восстановить бэкап, открыть после перезагрузки. Автоматизированные браузерные тесты в этом архиве пока не включены.
